Overview

Leafy is a plant doctor in your pocket. Snap a leaf, understand the disease, know what to do next. It is a clean rebuild of the DAHON prototype as a monorepo: Next.js talks to FastAPI over REST, and the browser only ever talks to Next.js.

Goals

Product

Read the leaf, act on it

A member uploads one leaf photo and gets the plant, the disease, causes, symptoms, treatment and prevention in short panels.

Trust

Real accounts, private scans

Real sign in replaces DAHON's client supplied id and plaintext passwords. Scans, history and account data are private.

Knowledge

A public handbook

13 plants and 27 diseases with causes and treatments, readable without an account and indexed for search.

Quality

Fast, calm, accessible

Lighthouse scores of 90 or more, WCAG 2.2 AA, a calm scientific voice, and a documented design system.

Stack at a glance

LayerTechnology
WebNext.js 15 App Router, TypeScript strict, Tailwind, React Three Fiber for 3D scenes.
APIFastAPI on Python 3.12, SQLAlchemy 2 async with asyncpg, Alembic migrations, layered routers, controllers, services and repositories.
Data and servicesPostgreSQL 16 (citext, pg_trgm), S3 compatible storage (MinIO in development). No email system: Leafy sends no email.
Known issue: sample images

Some images in the DAHON dump are corrupted or mislabelled, so the extractor could not produce disease reference photos. Disease pages say "Reference photos coming soon" until a clean image set exists. Provenance and licensing must be checked before any public deploy.

In short: the app is built end to end. Only the real ML model (the teammate’s) is missing.

Where the project stands

Built

Everything except the model

Seed data (13 plants, 27 diseases). The API: auth, Google (Firebase), account, catalog, scans, feedback. The web app: design system, splash, landing, handbook, auth, member shell, dashboard, account and the scan journey. Plus this document.

Not built

Four open items

1. The real ML model, written by the teammate. 2. Disease reference images, blocked by corrupt DAHON sample blobs. 3. The Firebase console setup (enable Google, authorized domains, key restriction) and a manual check with a real Google account. 4. Hosting, which is undecided.

Confirmed decisions

Auth

Cookies set by Next.js

JWT access token (15 min) and a rotating refresh token (30 days, 90 day family cap) in httpOnly cookies. Tokens never reach page scripts and there is no browser CORS.

Auth

Google sign in

Continue with Google beside email and password, through Firebase Auth. The browser gets a Firebase ID token from a popup and FastAPI verifies it against Google's public certificates, so there is no client secret.

Storage

Two buckets, public handbook

Private leafy-scans (presigned links, 10 minutes) and public leafy-catalog. The handbook is public; scans, history and account are private. Scan images are not used for training unless the team decides so and updates the Privacy Policy.

Data

Seed from DAHON

The DAHON dump seeds the catalog now. Joel's dataset swaps in later through the same seed format.

ML

One function contract

predict(image: bytes) -> dict[str, str] returns {"plant": slug, "disease": slug, "healthy" or "unknown", optional "confidence": "0.93"}. It receives the sanitized JPEG, long edge at most 2048 px, EXIF stripped. The stub raises NotImplementedError, which maps to 503 ml_unavailable.

Email

No email, recovery through Google

Leafy sends no email: SMTP, verification, reset links and notices are gone, and every signed in user can scan. Forgot your password? Sign in with Google using the same email, then set a new password in Account. A Google sign in under 10 minutes old needs no current password.

Tooling

Default toolchain

Python 3.12, uv, ruff, pytest, SQLAlchemy 2 async with asyncpg and Alembic. pnpm, Next.js 15, Tailwind.

UI

Leafy brand and rules

Dark forest default with light mode. Josefin Sans Light caps, Poppins, Manrope. Titles of one or two lines, no hyphenation, sideways panels. English only for v1, strings in one dictionary.

UX

Honest progress

Scans return 202 and run in the background. The UI shows real upload percent, then Checking image, Analyzing leaf, Saving result, Done.

Speed

Lighthouse is the yardstick

Four categories at 90 or more on mobile. LCP at most 2.5 s, INP at most 200 ms, CLS at most 0.1.

What closes the four open items

ML

Plug in the model

The teammate subclasses MLInferenceService and sets ML_SERVICE=package.module:Class. No other code changes.

Images

A clean image set

Disease reference photos come from a clean source, such as Joel’s dataset, through the same seed format. Licensing is checked first.

Google

Set up Firebase Auth

Enable Google in the Firebase console, check the authorized domains, restrict the browser API key, set FIREBASE_PROJECT_ID and the NEXT_PUBLIC_FIREBASE_* values, and keep GOOGLE_MOCK off.

Hosting

Pick a host

Then write the Dockerfiles, set S3_PUBLIC_ENDPOINT, and run PageSpeed Insights on the public URL.
