Security and verification

What protects accounts and uploads, the speed targets the site must meet, how the work is proven, and what is still open.

Security checklist

AreaControl
CookieshttpOnly, Secure in production with the __Host- prefix, SameSite=Lax (Strict would drop the session from email links), Path /. leafy_at lasts 900 s, leafy_rt 30 days.
Request originOrigin check (assertSameOrigin) on every state changing Next handler. sanitizeNext accepts only paths that start with / and not //.
Network exposureFastAPI is not published in production. It trusts X-Forwarded-For only from the compose network.
Passwordsargon2id, with a dummy hash check on unknown email so timing does not reveal accounts. Length 10 to 128, not the email, not in a common list.
TokensRefresh and email tokens are stored hashed (sha256). Refresh rotation with reuse detection revokes the whole family. Email tokens are single use with atomic consume.
Uniform errorsOne message for wrong credentials, one for bad email links, and forgot password is safe against enumeration (always 200).
Uploads8 MiB cap enforced at Next, in ASGI middleware and in the streaming read. Magic byte sniff, Pillow decode, 40M pixel cap, EXIF and GPS stripped by re-encoding, server generated keys. Long edge capped at 2048 px and re-encoded as JPEG; the model receives this sanitized JPEG.
Rate limitsPer ip, email and user limits (slowapi in memory for v1).
StoragePresigned URLs signed against S3_PUBLIC_ENDPOINT. Private scan bucket links last 10 minutes.
Browser headersCSP with nonce, HSTS, frame-ancestors 'none', nosniff. Token pages send Referrer-Policy: no-referrer.
Google sign inPKCE, state and nonce. Exact redirect URI allowlist. ID token checked server side (signature via cached JWKS, iss, aud, exp, nonce, email_verified). Secret only on the API. OAuth cookie single use and 10 minutes long.
Data accessEvery scan query is scoped by user_id. Another user's scan answers 404.
LoggingNo secrets or tokens in logs. Static error messages, never str(exc). Audit log line for Google link and create events.
Supply chainpip-audit, pnpm audit and a gitleaks secrets scan in CI. No third party analytics or trackers.

How we get there

AreaApproach
RenderingServer components and ISR for the public handbook and landing. Route level code splitting. No heavy libraries on public pages (tree shaken drei imports, framer-motion LazyMotion).
Fontsnext/font self hosted and preloaded: 3 families, limited weights, display: swap, adjustFontFallback.
Imagesnext/image for static imagery (AVIF and WebP, sized, priority only on the LCP image). Catalog images pre-resized at seed time.
3DThree.js loads after idle by dynamic import, with a static poster as the LCP candidate. One canvas per page, frameloop="demand", DPR cap. Models are Draco or meshopt compressed under 300 KB.
Caching and networkBrotli or gzip. Cache-Control immutable for hashed assets and 3D models. preconnect to the S3 public host.
Layout stabilityExplicit sizes, reserved panel heights, and content-visibility: auto for offscreen panels.
Third party scriptsNone.

Glossary

TermMeaning
Access tokenShort lived (15 min) JWT sent as a bearer token to the API.
Refresh tokenOpaque token valid 30 days that is replaced on every use. A family lasts at most 90 days.
Reuse detectionReplaying an already rotated refresh token after the grace window revokes the whole family.
PKCEProof key for code exchange. A secret created per sign in that stops a stolen authorization code from being used.
NonceA one time value tied to the Google ID token so it cannot be replayed.
EnvelopeThe fixed JSON shape {success, data, error} of every API response.
SlugA lowercase URL name for a plant or disease, such as early-blight.
VerdictThe scan outcome: disease, healthy or unknown.
StageThe step of a processing scan: validating, analyzing or saving.
Keyset cursorPaging by the last seen (created_at, id) instead of an offset, so deep pages stay fast.
Presigned URLA temporary signed link that lets the browser read one stored image directly.
OutboxThe storage_deletion table that records image keys to delete, so deletes survive an S3 outage.
ISRIncremental static regeneration: pages built ahead and refreshed on a timer (1 hour for the handbook).
Wave and gateA wave is a batch of parallel work. A gate is the set of checks that must pass before the next wave.
LCP, INP, CLSWeb vitals for load speed, responsiveness and layout stability.
DAHONThe original prototype. The word means leaf in Filipino. It is credited as the origin, not used as the brand.
