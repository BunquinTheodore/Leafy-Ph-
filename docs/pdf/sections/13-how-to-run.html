How to run

Five commands on Windows, no Docker. The script starts Postgres, storage, Mailpit, the migrations, the seed, the API and the web build, with throwaway local secrets and the mock Google provider.

Quickstart

You need Node 20 or newer, pnpm, uv, and the PostgreSQL 17 binaries. Set PG_BIN if they are not in C:\Program Files\PostgreSQL\17\bin. Run these from the repository root.

git clone https://github.com/BunquinTheodore/Leafy-Ph-.git; cd Leafy-Ph- cd api; uv sync; cd .. # 1. API dependencies cd app; pnpm install; cd .. # 2. web dependencies .\scripts\dev\run-all.ps1 # 3. services, migrations, seed, API, web start http://127.0.0.1:3000 # 4. open the app .\scripts\dev\run-all.ps1 -Stop # 5. stop everything

Where things run

AddressWhat it is
http://127.0.0.1:3000The app, a Next.js production build.
http://127.0.0.1:8000/docsThe API and its interactive docs.
http://127.0.0.1:8025Mailpit inbox. Verification and reset emails land here.
127.0.0.1:5433Project local Postgres. Port 5432 is never touched.

The script is safe to run again: it starts what is not running, applies alembic upgrade head, runs python -m app.seeds, and writes logs to .dev/logs.

The model while it is missing

The script runs with ML_SERVICE=dev-fake. It returns a label picked from the image hash, so the whole scan journey can be tried. It logs a loud DEV ONLY warning and refuses to start when ENV=prod.

SwitchEffect
-MlService stubUse the unimplemented stub. Every scan fails with Analysis isn’t available right now.
-SkipBuildReuse the last next build.
-E2ERate limits off, a 1 second resend cooldown, and a second stack with the stub (API :8001, web :3001).
-StopStop the API, the web servers and the dev services.

Before launch: placeholders and open items

Details the team still has to supply live in app/src/lib/site-config.ts. Each one shows on the site as a visible TODO marker, and a unit test fails if one stops being a marked value without being replaced on purpose.

ItemWhat to do
LEGAL_CONTACT_EMAILPut the real contact address into the Privacy Policy and Terms of Use.
TEAM_MEMBERSAdd the three real names for the About page.
Privacy Policy and TermsThe text is a plain language draft. Get a legal review.
Google sign inCreate the OAuth client, set GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GOOGLE_REDIRECT_URI and GOOGLE_MOCK=0.
ML modelPlug it in with ML_SERVICE=package.module:ClassName (see the ML integration section).
S3_PUBLIC_ENDPOINTSet the real public storage host for both api and app.
Photo provenanceCheck licensing for the handbook images.

The full suite signs in with Google through the mock provider: /api/auth/google?email=someone@example.com picks the identity. With Docker instead, copy .env.example to .env, edit the secrets, and use docker compose. The Dockerfiles are not written yet.
