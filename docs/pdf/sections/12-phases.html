Build phases and workflow

Work followed phases 0 to 15, plus 12b, in order of dependency. Tests came first, independent work ran in parallel with disjoint folders, and no wave started before the previous gate was green. Everything is built except the real ML model and the items that need a host.

Timeline in four waves

Operating rules and safety

RuleWhat it means
Dependency firstPhases run in order of dependency. Independent work runs in parallel with subagents, each owning disjoint folders. No phase starts before the previous gate is green.
TDD by defaultTests first for the API and Next logic. UI visuals are verified in a real browser.
Small conventional commitsOne commit per green phase (feat:, fix:, test:, chore:), so any phase can be reverted alone. No push until the team says so, no --no-verify, no force operations.
PreflightTools, free ports and inputs are checked first. With no Docker, development uses native services.
Protected inputThe DAHON folder is never modified, and destructive commands are not used without asking.

Execution workflow

Gates

Gate 1After wave 1. Tests, coverage, migrations, seeds and five reviewers.
Gate 2After wave 2. Full stack, browser pass and security review.
Final gateAfter wave 3. All suites green, scores met, last review.
GateWhat must be true
Gate 1
  • pytest green, 80 percent or more coverage on the backend work.
  • pnpm test and pnpm build green.
  • Migrations apply on an empty database.
  • Seeds --check passes.
  • Five reviewers (code, FastAPI, security, React, TypeScript) run in parallel. Every CRITICAL and HIGH finding is fixed.
Gate 2Full compose stack up. Manual browser pass: register, verify via Mailpit, upload with a fake ML service, progress UI, result panels, history, delete, forgot and reset, delete account. Ownership and refresh tests. Security review of upload and S3 paths.
Final gateAll suites green, Lighthouse thresholds met, a last code and security review of the whole diff, and a short report of what was and was not verified.

Stop and ask

Even in auto mode the work stops and asks before these steps. A step that fails twice for the same cause stops and reports.
